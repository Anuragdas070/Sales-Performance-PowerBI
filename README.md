# Sales Performance Dashboard

An interactive sales performance dashboard developed using Microsoft Power BI to analyze sales, profit, products, countries, business segments, and monthly sales trends.

## Project Overview

This project focuses on analyzing business sales data and presenting key performance indicators through an interactive Power BI dashboard.

The dashboard allows users to explore sales performance using filters for:

- Year
- Country
- Segment

## Key Performance Indicators

- Total Sales: 118.73M
- Total Profit: 16.89M
- Units Sold: 1.13M
- Profit Margin: 14.23%

## Dashboard Visualizations

The dashboard includes:

- Sales by Country
- Sales by Segment
- Profit by Product
- Monthly Sales Trend
- Interactive Year, Country, and Segment filters

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Insights

- Total sales across the dataset are 118.73M.
- Total profit is 16.89M, resulting in a profit margin of 14.23%.
- The United States has the highest sales among the countries shown.
- Government is the largest contributing business segment by sales.
- Paseo generates the highest profit among the products analyzed.
- Monthly sales vary across 2013 and 2014, with noticeable changes during the year.
